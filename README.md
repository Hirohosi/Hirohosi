# 開発の紹介

# 🕒 勤怠管理 SaaS（開発中）

> **中小企業向けのシンプルで使いやすい勤怠管理システム**  
> 打刻 → 勤怠集計 → 締め処理 → 給与連携（弥生給与 Next 対応）までを一括管理。  
> Multi-tenant / RBAC / Stripe 課金 など、本格的な SaaS アーキテクチャを個人開発で構築。

---

## 🚀 サービス概要

勤怠の打刻・休暇申請・残業計算・月次締めまでを  
**シンプルで直感的な UI** で管理できる勤怠管理 SaaS。

- PC / スマホ / タブレット対応
- QRコード / PIN 打刻
- 従業員・管理者で操作 UI が切り替わる
- 弥生給与 Next など給与システムへ CSV 連携可能

中小企業が「できるだけ操作を覚えずに」運用できる設計を目指している。

---

## 🎯 目的・解決したい課題

### プロダクトの目的
- 毎月の勤怠締め作業を **最小コスト化**
- 現場の「操作が複雑」という課題を排除
- 給与システム連携のための CSV 整形を自動化

### 解決したい課題
- 紙・Excel・LINE などの混在した勤怠管理
- 毎月の集計・休暇反映・残業計算の属人化
- 給与計算担当の手作業を圧縮
- 従業員・管理者の教育コストを軽減

## 🧩 機能一覧

### 従業員向け
- 出勤 / 退勤打刻（Web / QR / PIN）
- 休暇申請
- 打刻修正申請
- 自分の勤怠一覧確認

### 管理者向け

- Stripe による Seat 課金（ユーザー数に応じた料金）

## ✨ 工夫したポイント

### 1. **Multi-tenant 対応**
企業ごとに Workspace を分離し、  
データが混在しない設計に。

### 2. **RBAC（役割ベースの権限管理）**
- owner（全権）
- admin（承認・設定）
- staff（打刻・申請）

の3階層でアクセスを制御。

### 3. **勤怠計算ロジックの自動化**
- 休憩自動付与  
- 端数の丸め  
- 深夜労働時間  
- 法定外 / 法定内残業  
- 法定休日労働  

勤怠SaaSとして現実的に必要な計算を実装。

### 4. **CSV連携（弥生給与 Next フォーマット）**
給与計算担当者がそのまま取り込める形式でエクスポート可能。

### 5. **EventBridge + Lambda でバッチ処理**
- 締め処理
- データ補正
- 月次集計

を低コストで自動化。
